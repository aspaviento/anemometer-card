# Changelog

All notable changes to this project are documented here.

This project follows simple semantic versioning while it is pre-1.0:

- Patch releases fix layout, compatibility, and documentation issues.
- Minor releases may add card options or visible behavior.
- Breaking changes should be avoided before `1.0.0`; if unavoidable, document the migration path.

## 0.1.4

- Matched connectivity and battery indicator sizing with compact Home Assistant dashboard cards.

## 0.1.3

- Adjusted the history chart sizing so the expanded card aligns more closely with companion weather cards.

## 0.1.2

- Compacted the card layout for dashboard grid use.

## 0.1.1

- Replaced the animated anemometer with a static visual.
- Kept the direction marker above the anemometer artwork.

## 0.1.0

- Initial HACS-compatible release.
- Added speed, direction, battery, connectivity, and collapsible 24 hour history.
- Added Home Assistant card editor support.
